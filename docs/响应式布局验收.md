# 响应式布局与验收

更新日期：2026-09-18。适用于本地工作台与 GitHub Pages 合成演示。

## 布局行为

| 视口宽度 | 导航 | 内容适配 |
| --- | --- | --- |
| ≥1200px | 默认 232px 完整侧栏，可用左上角按钮折叠为 80px 图标栏 | 内容区随侧栏伸缩，工作台保留分栏 |
| 768–1199px | 默认 80px 图标栏，悬停显示名称，可手动展开 | 图表改为纵向排列，搜索入口保持可用 |
| <768px | 侧栏收起，点击左上角按钮打开抽屉 | 主内容占满宽度，搜索单独成行，表单单列 |
| <360px | 抽屉宽度仍预留可点击遮罩 | 指标卡单列，摘要和图例换行 |

侧栏使用动态视口高度并独立滚动。视口高度不超过 800px 时隐藏辅助介绍卡，将空间留给导航与账号操作；横屏小窗口也能滚动到设置、学校管理和退出入口。

手机抽屉支持内部关闭按钮、遮罩点击和 Esc。打开时锁定背景滚动并使主内容不可交互，Tab / Shift+Tab 在导航中循环；关闭后焦点回到菜单按钮。切换页面后自动关闭；跨越断点时清理抽屉状态、滚动锁定和临时折叠选择。

表格完整保留各列，在自身区域横向滚动，并提供可聚焦的滚动区域。详情标签可横向滚动；图表图例换行，图表容器随页面缩放。长文本与服务地址不会撑宽页面。弹窗高度受动态视口约束，内容内部滚动。移动端输入字号至少 16px，以避免 iOS 输入自动放大。

## 浏览器验证

使用 Microsoft Edge 验证以下视口：320×640、390×844、768×600、844×390、1024×600、1440×720、1920×1080。额外以 390×480 检查抽屉键盘交互与跨断点缩放。

- 本地版：12 条测试通过，包括 7 种视口、抽屉键盘与缩放、真实教师设置与学校管理，以及既有登录、导入、下载、追问、在线模型配置流程。
- Pages 版：9 条测试通过，包括同样的视口与导航检查，以及不收真实数据、不调用 API 的演示回归。
- 每种视口均遍历工作概览、我的课堂、教学洞察、分析报告、教研助手、空间设置；检查详情的画像、原文、建议、追问及上传弹窗。
- 检查页面无横向溢出，表格列保持可见、搜索可用、弹窗未超出视口、导航宽度和焦点状态符合预期。
- TypeScript、本地版构建、Pages 构建和 Prettier 检查通过。

这是桌面浏览器不同视口下的验证；尚未在实体 iPhone、Android 或 Safari 中实机验收。

```bash
cd frontend
npm run build
npm run build:pages
npm run test:e2e
npm run test:pages
```

真实教师/管理员流程需要隔离测试后端与 TEACHAGENT_E2E_PASSWORD。新增响应式测试共用 `e2e-shared/responsive.ts`，本地版与 Pages 分别执行。设置 TEACHAGENT_PAGES_URL 可对部署后的公开站点运行同一组 Pages 测试。
