## 实际离线 ASR 记录

- 输入：Windows 本地中文语音合成产生的约 29.42 秒测试视频。
- 模型：faster-whisper-tiny，CPU、int8。
- 完整本地管线耗时：3.96 秒，仅本次设备与短样本结果，不代表真实课堂性能承诺。
- 输出：1 张抽帧，7 个话语片段，1 处提问线索，2 处互动邀请。
- 运行期间网络连接尝试：0。
- 模型实际存在识别错误，例如把“函数”识别成“寒书”。本记录不宣称达到学校课堂准确率标准；正式部署建议选择更大的本地中文适用模型，并以校方实际录音验收。

## 复现命令

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
cd frontend
npm ci
npm run build
npm run test:e2e
```

浏览器真实账号流程需设置本地测试账号环境变量，不提供公共默认密码。执行界面见 `docs/images/`，全部为合成示例。
