## 行为约定

1. OpenAI 兼容请求携带 `stream=true`，解析 `choices[].delta.content`；Ollama 解析 `message.content` 与 `done`。浏览器接收自有 SSE 事件，不再等待全文后播放动画。
2. 规则模式直接返回完整规则建议，不伪装模型流；Pages 为明确标识的合成流式模拟，停止和重试不会访问后端或模型。
3. 生成中显示“停止生成”，等待首字时同样可停止。后端停止读取并关闭上游连接；界面保存部分内容并显示“已停止”。关闭上游 HTTP 不代表供应商必定立即停止计费或内部计算。
4. 最近一轮可“重试”或“重新生成”，使用当前保存的模型设置，复用问题与轮次 ID，递增 attempt，替换原回答，不增加重复问题；旧版本回答不另行保留。
5. 不完整问答不进入后续模型上下文。只有完成的历史进入最近 8 条消息；课堂上下文仍限于现有前 100 个转写片段。
6. 断流、空响应、非法格式、超长响应、长度截断、认证失败、限流和超时均明确报错。已出现模型文字后不再拼接规则回答。
7. 切换页面会中断当前请求；再次打开显示已保存历史。服务启动将 running/stopping 标记为 interrupted。250ms 保存节流与最终保存保证正常中断可恢复文字；强制断电可能损失最后尚未写盘的片段。
8. 单个课堂只允许一个活动生成，数据库唯一索引和事务阻止并发重复。跨账号、无效 CSRF 和过期重试被拒绝。

## 接口与数据

`POST /api/lessons/{lesson_id}/chat/stream`，请求示例：

```json
{
  "message": "某个环节为何互动偏少，可以怎么改？",
  "request_id": "db2e5e8a-3aaf-4c7e-bf44-8b8c4bbf45ba",
  "retry": false,
  "expected_attempt": 1
}
```

响应为 `text/event-stream`；每条 `data` 是 JSON。`start` 返回轮次与 attempt，`delta` 返回本次新增 content 与 engine，`done` 返回最终 status、content、error、engine、轮次与 attempt。等待首字时每 10 秒发送注释保活。流已建立后的失败以 `done.status=error` 返回，HTTP 状态仍为 200。

`POST /api/lessons/{lesson_id}/chat/{request_id}/stop` 请求停止；生成任务观察到停止后关闭上游并保存。终态停止操作为幂等操作。重试向 stream 接口提交相同 request_id 与问题、`retry=true` 和上次 attempt；重复或过期请求返回 409。

`GET /api/lessons/{lesson_id}/chat` 合并旧 messages 与新 chat_turns；助手消息增加 request_id、status、error、attempt。旧非流式 POST 接口保留兼容，现行 WebUI 使用新流式接口。

新增本地表 chat_turns；旧库启动时自动创建，不重写旧 messages。账号备份 manifest 升级 schema 2，包含 chat_turns；账号存在活动生成时拒绝备份。运行方式仍为单进程 Uvicorn，多 worker/副本需要额外的任务租约与启动恢复协调。

## 验证证据

本机 Python 3.12、Windows、Microsoft Edge；使用独立测试数据库与合成课堂材料。

| 检查 | 结果 | 证明范围 |
| --- | --- | --- |
| `.venv/Scripts/python -m pytest -q --tb=short` | 55 passed | 原有后端回归及 12 项新增流式协议/状态检验 |
| `npm run test:e2e -- --workers=2` | 16 passed | 真实本机服务下的教师流程、流式交互、Markdown、安全处理、320–1920px 响应式 |
| `npm run test:pages -- --workers=2` | 10 passed | 合成演示分段、停止、重试，无课堂 API 请求，响应式导航 |
| `npm run build` / `npm run build:pages` | 通过 | TypeScript 与两种生产构建 |
| `npm run format:check` | 通过 | 前端源码及测试格式 |

关键测试不是只检查最终文字：

- `tests/test_chat_stream.py` 启动真实 TCP HTTP 服务，故意暂不发送末段。测试在释放末段之前已收到第一段；同时验证 SSE / NDJSON、UTF-8 跨网络写入、CRLF 和完成标记。
- 同一测试实际观察模型连接被关闭，覆盖首字前停止、部分输出停止和浏览器断连；检查 SQLite 保存的内容与状态，并重试确认只有一对问答。
- 覆盖失败部分文字、排除失败上下文、旧问题重试限制、跨账号与 CSRF、并发请求、服务重启与备份。
- `frontend/e2e/chat-streaming.spec.ts` 使用真实 FastAPI 与可控 HTTP 模型服务。页面显示首段时服务端响应尚未结束；后续验证停止确实关闭连接、失败可重试、问题不重复、离开页面取消和向上滚动不被抢走。
- Markdown 标题、列表、代码、表格仍可读；原始 HTML、脚本和远程图片不会执行或自动加载。

## 发布与实际部署

现有 `.github/workflows/ci.yml` 自动运行后端、本地浏览器和 Pages 浏览器检查，通过后部署 Pages。Nginx 示例关闭 `proxy_buffering`、`proxy_cache` 和 gzip，接口也返回 `X-Accel-Buffering: no`。

Pages 不运行 FastAPI，也不处理真实课堂；真正模型流式服务需要本地部署。兼容协议使用真实本机 HTTP 模拟服务验证，尚未用学校实际 Ollama 模型或外部供应商凭据进行推理验收；Nginx 配置已更新，但未在本机启动 Nginx 进行代理实测。
