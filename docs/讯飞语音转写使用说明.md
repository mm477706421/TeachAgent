# 科大讯飞语音转写（1.3.0）

## 适用范围与数据流

默认保持本地 Whisper 转写。讯飞是可选的云端语音听写方式，与 OpenAI 兼容教研追问设置相互独立。选择讯飞后，服务器提取 16kHz、单声道、16bit PCM 音轨，通过加密 WebSocket 发往 `iat-api.xfyun.cn`；原视频与参考帧不发往讯飞。转写结果回存学校服务器，文本蒸馏及教学画像仍在本地计算。

讯飞会接收课堂音频，此模式不属于“全程离线”。学校应在取得相应授权后使用；如资料不得外发，请始终选择本地 Whisper 并禁用服务器的外网出口。云端请求可能消耗讯飞额度，具体计费、数据处理与留存规则以学校和服务商的约定为准。

## 管理员配置

1. 在讯飞控制台为应用开通**语音听写（流式版）WebAPI**。APPID、APIKey、APISecret 三项必须来自同一个应用。本版本并非“录音文件转写”或另一个“实时语音转写”产品的协议。
2. 在服务器私有 `.env` 或 systemd 的 `/etc/teachagent.env` 设置下列变量。示例只展示变量名，不包含实际密钥。

```dotenv
IFLYTEK_APP_ID=填写应用编号
IFLYTEK_API_KEY=填写接口密钥
IFLYTEK_API_SECRET=填写签名密钥
```

3. 安装更新后的依赖（新增 `websockets==15.0.1`），重启应用。Docker Compose 会从 `.env` 读取这些变量；修改后重新创建容器。
4. 在“空间设置 → 本地运行状态”检查“讯飞语音听写”。“已配置”只代表三项变量完整，不代表权限、余额和网络已验证。先用获得授权的短测试录音验证。
5. 保持服务器时钟准确，并允许后端访问 `wss://iat-api.xfyun.cn/v2/iat`（TCP 443）。浏览器不直接连接讯飞。

密钥由学校管理员管理，不在网页中显示，不放入 GitHub、Pages、Release 或教师导出备份。服务配置对该部署生效，但不会自动改变任一教师的默认转写方式。移除三项配置并重启可以停用后续云端转写。

## 教师操作

![讯飞转写选择与授权](images/iflytek-upload.png)

1. 登录，点击“上传新课堂”，填写课堂名称、学科及班级。
2. 在“语音转写服务”选择“科大讯飞（云端语音听写）”。每次打开上传窗口，默认仍是本地 Whisper。
3. 阅读音频发送、分段及费用说明，勾选“我已获得授权，同意本次及重试任务将课堂音频发送到科大讯飞”。未确认时不能提交，后端也会检查。
4. 选择视频，点击“上传并开始分析”。讯飞任务显示“讯飞云端转写：正在发送音频”；完成后照常查看画像、证据、建议及报告。
5. 课堂详情保留讯飞来源标记，转写片段标注“音频块时间范围，非逐句对齐”。Word / HTML / JSON 报告保留分析中的方法边界。

选择会绑定到该课堂。失败重试继续使用原转写服务及原授权，可能再次产生费用；不会静默切换到本地或云端。若希望换回本地，请重新上传并选本地 Whisper。教师只能操作自己的课堂。授权事件记录在审计日志中。

## 长课堂与识别精度

官方流式听写单次支持 60 秒以内音频，静音后端点最大 10 秒。本版本采用连续 **8 秒音频块**，每个块独立建立会话，并按 40ms / 1280 字节发送；全片顺序处理，不截取前一分钟。开启 `dwa=wpgs`，合并服务端的动态替换结果。

此方案避免长静音导致一个会话提前结束，但固定切分可能截断词句上下文。时间戳表示音频块覆盖范围，**不是逐句或逐词对齐**；环节时长、片段数量、语速等会受分段影响，应结合录音复核。不进行声纹分离，不保证比所有本地模型更准确。

发送速度接近实时，加上握手与结果等待，处理耗时通常不少于音频时长。长课会产生多个计费请求；并发仍为单任务队列。连接错误会明确失败，修复后手动重试，全片重新处理，不支持断点续传。

如需要更准确的纯本地方案，可由管理员将 tiny 模型升级为 small、medium 或适合硬件的更大模型，改善拾音、降低噪声，并用本校样本对比。更大模型需更多内存、算力和时间。可先校对文本，再通过文本导入重新分析。

## 排错与验证边界

- 尚未配置：检查三项环境变量，重启实际运行的服务；不要把语音认证信息填入 OpenAI 对话设置。
- 鉴权或连接错误：核对同一应用的三项信息、语音听写权限、外网及系统时间。
- 服务端返回错误码：在讯飞控制台检查服务开通、余额和限流；界面只显示错误码，不泄露签名 URL 或服务原始错误内容。
- 结果为空：检查音轨是否为有效普通话语音、音量及录音质量。
- GitHub Pages：仅显示新功能说明，不接收音频、账号密码或讯飞密钥，也不发起讯飞请求。

2026-09-28 已用 Windows 合成普通话“同学们，今天我们学习三角形。请大家思考，三角形的内角和是多少度？”验证真实 WebSocket 认证、传音与返回识别文本。该验证未使用学校音频，也不是课堂识别率基准测试。真实教室噪声、多人讲话、长课的识别质量仍需学校用获授权的样本验收。
